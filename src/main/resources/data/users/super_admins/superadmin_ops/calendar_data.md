# superadmin_ops Calendar Data

## Seed source

- `src/main/resources/data/02-demo-role-data.sql`

## Timeline model

- Relative to `CURRENT_DATE`
- One completed activity block from the last week
- A live item on the current date
- A forward item one week ahead

## Seeded activity

- Workout: `Super Admin Ops Reset`
- Schedule: `Super Admin Incident Calendar`
- Recurring task: `Incident and risk pass`
- Goal: `Protect escalation coverage`
