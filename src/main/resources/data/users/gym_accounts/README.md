# Gym Accounts

Gym admin demo accounts are split per account so gym codes, operations setup, and seeded planning data can be reviewed cleanly.

## Accounts

- `demo_gym`: Harbour Strength Club account
- `gymadmin_demo`: FitZone Gym Cardiff account

## Folder contract

Each gym account folder contains:
- `info.md`
- `account_setup.md`
- `calendar_data.md`
