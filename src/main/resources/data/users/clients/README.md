# Clients

Client demo accounts are split into individual folders so each seeded client can be reviewed in isolation.

## Accounts

- `demo_client`: flagship premium coached client linked to `demo_trainer`
- `demo`: returning client with live current-week data and a lapsed premium state, linked to `trainer_demo`
- `demo2`: starter comparison account with lighter self-managed activity

## Folder contract

Each client folder contains:
- `info.md`
- `account_setup.md`
- `calendar_data.md`
