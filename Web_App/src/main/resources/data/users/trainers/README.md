# Trainers

Trainer demo accounts are organised by username so verified-coach records, trainer codes, and seeded coaching timelines stay easy to audit.

## Accounts

- `demo_trainer`: flagship verified trainer linked to `demo_client`
- `trainer_demo`: verified trainer with a second fully prepared coaching account linked to `demo`

## Folder contract

Each trainer folder contains:
- `info.md`
- `account_setup.md`
- `calendar_data.md`
